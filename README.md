# 🚀 **Project Overview**

## **Study Forest**

> Many people want to set goals and build consistent habits, but maintaining them over time can be challenging. **Study Forest** is a service designed to help users build study habits and stay motivated by providing points based on their focused study time.

### **Key Features**

* Habit creation and management
* Points awarded based on focused study time
* Study group activities

### **Project Duration**

* 2025.03.21 ~ 2025.04.10

# 🔨 **Detailed Team Contributions**

### 🎉 **Lee Jisoo B**

* **Study Detail Page**

  * Users can view detailed information about a study by selecting a study from the study list.
  * Displays the top 3 supporting emojis and their counts, study name, creator's nickname, study description, study points, and habit records.
  * Habit records can be updated from the Today's Habits page.

* **Delete Study**

  * Users can delete a study by entering the password they provided when creating the study.
  * The study is deleted only when the entered password matches the original password.

### 👑 **Kim Hongseop**

* **Edit Study**

  * Users can edit study information by entering the password provided when the study was created.
  * Editing is allowed only when the entered password matches the original password.

* **Add Supporting Emojis**

  * Users can add supporting emojis on the study detail page.

### 🏆 **Lee Taebin**

* **Start Today's Focus**

  * Users can set a study duration using a timer and start their focus session.
* **Complete Today's Focus**

  * The focus session is completed when the configured study time ends.
  * Users receive a base reward of 3 points upon successful completion, plus 1 additional point for every 10 minutes of study time.

### 🔮 **An Sebin**

* **View Today's Habits**

  * Users can access Today's Habits by entering the password they provided when creating the study.
  * Displays the current time and today's habit list.
  * Provides navigation to the Today's Focus page and the Study Home page.

* **Create Today's Habits**

  * Users can create habits that repeat every day.

### 🎯 **Lim Jeongbin**

* **Create a Study**

  * Users can create a study by entering a nickname, study name, brief introduction, background image, password, and password confirmation.

* **View Today's Focus**

  * Users can access the Today's Focus page by entering the password used when creating the study.
  * Displays the points earned so far and provides timer controls.

### ✨ **Choi Minkyung**

* **Edit Today's Habits**

  * When a habit name is edited, the name is updated across all previously associated habit records.
  * When a habit is ended, it is discontinued starting from the current day without affecting previous records.
  * When a new habit is added, it starts from the current day and does not appear in study details for previous dates.

* **Check Today's Habits**

  * Users can check or uncheck habits they have completed.
  * The check status resets every day.
  * Checked habits are recorded in the habit history table on the study detail page.
  * The habit history table allows users to view their records on a weekly basis.

### 💎 **Park Mingyu**

* **Layout, Header & Footer**

  * Implemented the overall layout and responsive design.
  * Implemented shared header and footer components.

* **Study List**

  * **Recently Viewed Studies**

    * Uses LocalStorage to display studies that the user has recently viewed.
  * **Study List**

    * Provides pagination and search functionality.
    * Supports sorting by points in ascending/descending order, newest first, and oldest first.
